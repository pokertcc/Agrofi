📖 Guia Prático: Como Configurar Cada Fazenda no AgroFi

Orientações passo a passo para vincular carteiras Ethereum e cadastrar novos imóveis rurais (CAR).

Configuração Centralizada
1

Editar o Arquivo farms_config.json

As fazendas e suas carteiras são mapeadas de forma padronizada no arquivo farms_config.json na raiz do projeto. Para associar uma nova fazenda a uma carteira sua, basta preencher: 

{
  "land_id": "TALHAO-NOVO-005",
  "farm_name": "Sua Fazenda Nova",
  "car_code": "UF-1234567-XYZ...",
  "wallet_address": "0xSeuEnderecoMetaMask...",
  "nft_token_id": 5,
  "credit_limit_usd": 300000.0
}
2

Importar Carteiras no Rabby / MetaMask

Para testar operações de assinatura e empréstimos na testnet Sepolia ou no nó local Anvil (http://127.0.0.1:8545):

  1. Abra o Rabby ou MetaMask e clique em Importar Conta / Chave Privada;
  2. Cole a chave de teste da fazenda (disponível no arquivo protegido .env);
  3. Conecte à rede Sepolia ou crie uma RPC local com Chain ID 31337.
3

Vínculo CAR (SICAR) & Token NFT RWA

Cada fazenda possui um código CAR oficial registrado no SICAR. No AgroFi:

  • O polígono é ingerido via GeoPandas no arquivo src/etl/sicar_ingestor.py;
  • O contrato AgroFiVault.sol vincula o carCode ao tokenId do NFT;
  • Apenas a carteira dona do NFT ou aprovada pode contrair empréstimos contra o colateral.
4

Como Funciona o Redirecionamento (8080 ➔ 8501)

Ao conectar a carteira pelo botão principal ou pelo card da fazenda, a aplicação faz o repasse transparente dos parâmetros via URL:

http://localhost:8501/?land_id=TALHAO-MT-001&wallet=0x7099...

O Streamlit lê os parâmetros nativamente, seleciona automaticamente a fazenda correta no mapa MapLibre GL JS, exibe o selo de carteira conectada e atualiza os limites de crédito.
